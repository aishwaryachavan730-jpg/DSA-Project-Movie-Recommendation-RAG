# 🎬 AI Movie Recommendation System using RAG

## 📌 Project Description

This project is an AI-powered Movie Recommendation System built using Retrieval-Augmented Generation (RAG). It recommends similar movies using semantic search with Sentence Transformers and FAISS. The application also supports voice search, image captioning, and an AI chatbot for answering movie-related questions.

---

## 🚀 Features

- 🎬 AI Movie Recommendation
- 🔍 Semantic Movie Search
- 🤖 AI Movie Chatbot
- 🎤 Voice Search
- 🖼️ Image-to-Text (Movie Poster Captioning)
- ⭐ Favorite Movies
- 📊 FAISS Vector Search
- 💬 RAG-based Retrieval

## Dataset

The original dataset used in this project is larger than GitHub's 100 MB file limit.

To run this project:

1. Download the dataset from Kaggle or TMDB.
2. Place the files inside the `DataSet/` folder.
3. Run the preprocessing scripts.


## ▶️ Installation

```bash
git clone <repository_link>

cd Movie-Recommendation-RAG

pip install -r requirements.txt
```
